# Програмне забезпечення технології цифрового двійника електроскутера

Програмне забезпечення цифрового двійника призначена для оперативного моніторингу в реальному часі, збирання телеметричних даних, збереження історії, аналізу стану, прогнозування відмов та двостороннього керування режимами роботи електроскутера протягом усього його життєвого циклу.

**Об’єкт дослідження:** Електроскутер є індивідуальним електричним транспортним засобом, який використовує акумуляторну батарею для живлення електродвигуна та електронних систем керування.

**Призначення об’єкта:** Електроскутер є персональним електричним засобом міської мобільності, призначеним для перевезення пасажира та вантажів у межах міської інфраструктури.

Робота виконується в рамках вивчення дисципліни **«Програмне забезпечення технології цифрових двійників»**.

### Основні режими функціонування об'єкта:
- **Швидкісні режими:** Обмеження максимальної швидкості (30, 40 та 50 км/год) з можливістю зміни режиму через керувальні команди.
- **Маневрування:** Підтримка руху вперед та назад.
- **Аварійні та нештатні стани:** Моделювання критичних відхилень (перегрів електродвигуна, надмірний струм, падіння напруги або критичний розряд акумулятора) для перевірки систем сповіщення та безпеки.

### 📊 Телеметричні сигнали та параметри (8 каналів):

| Ідентифікатор | Назва сигналу | Джерело | Тип | Одиниці | Діапазон | Частота ($f_д$) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| `SIG_VEL_01` | Швидкість руху | Ходова частина | Аналоговий | км/год | 0 – 60 | 10 Гц |
| `SIG_RPM_02` | Частота обертання двигуна | Електродвигун | Аналоговий | об/хв | 0 – 3000 | 10 Гц |
| `SIG_CUR_03` | Струм акумулятора | Акумуляторна батарея | Аналоговий | А | 0 – 50 | 1 Гц |
| `SIG_VOL_04` | Напруга акумулятора | Акумуляторна батарея | Аналоговий | В | 36 – 54.6 | 1 Гц |
| `SIG_TMP_05` | Температура електродвигуна | Електродвигун | Аналоговий | °C | -20 – 120 | 0.1 Гц |
| `SIG_SOC_06` | Рівень заряду (SoC) | Акумуляторна батарея | Аналоговий | % | 0 – 100 | 0.1 Гц |
| `SIG_BRK_07` | Стан гальмування | Гальмівна система | Дискретний | булевий | 0 / 1 | Подієво |
| `SIG_LCK_08` | Протиугінне блокування | Система захисту | Дискретний | булевий | 0 / 1 | Подієво |
